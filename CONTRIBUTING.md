# Contributing to MyStack

MyStack is publicly developed and welcomes bug reports, feature requests,
security reports, documentation improvements, and proposed code changes.

## Official governance

- Copyright owner and lead maintainer: Sakibur Rahman (`sakibweb`).
- Official organization: https://github.com/mystack-framework
- Official repository: https://github.com/mystack-framework/mystack
- Public contributors do not receive direct write, merge, release, or update
  authority merely by opening an issue, discussion, or pull request.
- The owner or an explicitly authorized maintainer reviews every requested
  change and decides whether, when, and how it enters the official project.

## Contribution process

1. Open an issue or discussion describing the problem or proposal.
2. Fork the repository and create a focused change.
3. Preserve copyright, license, NOTICE, security, compatibility, and test
   requirements.
4. Mark modified files clearly where required by Apache-2.0.
5. Run `php mystack doctor` and `php mystack smoke`.
6. Submit a pull request. Submission does not guarantee acceptance.

Unless explicitly marked "Not a Contribution", intentionally submitted work
is offered under Apache License 2.0, Section 5. Contributors retain copyright
in their own contribution while granting the rights stated by the License.

Do not include secrets, third-party code without compatible licensing, or use
the MyStack name in a way that implies an unofficial fork is official.
